# Editable asset pipeline

- `models/cadet.bbmodel`: original editable Blockbench project with 31 cubes, palette texture embedded, named armour bones and articulated forearm/shin/boot children. It was authored programmatically; Blockbench/Blender was not operated or visually verified.
- `animations/*.json`: original Player Animator/Emotecraft v3 JSON projects, including bend channels. The runtime copies live in `assets/mha/player_animations` and are regenerated by `tools/make_assets.py`.
- `interface/*.svg`: original crisp 24-unit technique icon sources. Runtime PNGs use the same silhouettes. Words and keys are never baked into the icons.
- `menu/academy_dawn.original.png`: full-resolution image-generation output, identical pixels in the runtime menu texture. See `menu/PROVENANCE.md` for tool, production prompt and scope.
- `tools/make_map.py`: complete authored build source. Outputs a standard structure NBT and matching runtime palette blueprint; NPC spawning and mission contacts are implemented by the mod.
- Photon effect authoring currently lives in `client/ClientPresentation.java`: a bounded one-shot emitter using the pinned Photon 2.2.9 API. **No exported `.fx` or Photon editor project has been validated yet.** Do not describe this pipeline as completed.
- `audio/*.wav`: six original mono 44.1 kHz masters, generated with authored oscillators, seeded noise and envelopes. Runtime Vorbis exports, event subtitles and synthesis parameters are included. See `audio/PROVENANCE.md`. Final perceptual mix and listening checks remain pending; no official audio is used.

Run `python tools/make_assets.py`, `python tools/make_map.py`, then `python tools/validate_assets.py` with Python 3, Pillow and nbtlib. Audio regeneration is separate: `python tools/make_audio.py` needs NumPy and soundfile/libsndfile with Vorbis. Existing runtime exports are included; Python is not needed to build or play the JAR. Editing the Blockbench source requires exporting/reconciling the geometry deliberately; rerunning the generator regenerates the authored baseline. Runtime exports are GeckoLib 4 geometry, not an arbitrary Blender mesh conversion.

Visual checks still required: standard/slim, first/third person, observer, crouch, swimming, riding, interrupted casts, partial sets, held items, shoulder/elbow/knee position and deformation. Passing source/schema tests is not a substitute for these checks.
